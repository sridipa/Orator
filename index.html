Frameworks

Mental models for organizing thought and commanding narrative flow.

STAR

Situation, Task, Action, Result

When to use

Behavioral interviews, performance reviews.

PREP

Point, Reason, Example, Point

When to use

Impromptu speaking, Q&A sessions.

SCQA

Situation, Complication, Question, Answer

When to use

Executive presentations, proposals.

MECE

Mutually Exclusive, Collectively Exhaustive

When to use

Problem-solving, categorizing data.

PPF

Past, Present, Future

When to use

Introductions, demonstrating trajectory.
